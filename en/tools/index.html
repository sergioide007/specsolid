A tool for every stage of the work.

Free and open source, written without frameworks. They work on their own and connect through spec.md.

Scrum Board SDD

Plan · web

A sprint board built around the spec. Manage sprints, velocity and technical debt, and export the active sprint as spec.md.

  • Planning with the team's real capacity
  • Burndown and historical velocity per sprint
  • Works offline; your data stays in your browser
  • Exports the sprint as spec.md for Alpaquitay AI
Learn about the board Open the board

Alpaquitay AI

Build · VS Code

An engineering assistant that understands the active spec and your Git history. Works with Claude, OpenAI, Ollama or LM Studio.

  • Panel with Studio, Architecture, Git, Skills and Settings
  • Reads spec.md as the sprint context
  • Skills: refactor, generate tests, create files, daily standup
  • Mermaid architecture diagrams from the spec
Explore Alpaquitay AI Open site

Manan kanchu AI

Verify · VS Code

Checks code before you commit. The name comes from Quechua for “what does not exist”, a nod to code no human wrote.

  • Probability that a snippet was AI-generated
  • 91 vulnerability patterns with CWE references
  • Detects 7 malicious-code categories
  • 14 built-in policy rules plus custom rules
Explore manan-kanchu Open site

The theory framework: how to write a good spec, which risks appear and what working without one costs.

  • 7-step flow, from business problem to deployment

  • Token cost simulator, with and without a spec
  • ADRs with context, decision, alternatives and trade-offs
