SPEC-DRIVEN DEVELOPMENT · VS CODE

Una extensión de IA para VS Code que trabaja desde la especificación.

Alpaquitay AI ayuda a convertir requisitos en cambios revisables. Organiza el trabajo alrededor de la especificación, propone diffs antes de escribir archivos y deja evidencia de las comprobaciones ejecutadas.

Instalar desde VS Code MarketplaceVer código fuente

Especificación antes del código

Alpaquitay usa `spec.md` y el contexto del repositorio para orientar tareas de ingeniería. El flujo busca que el objetivo, los límites y la verificación estén claros antes de aceptar cambios.

Revisa el diff antes de aplicar

Los cambios generados se presentan como propuestas acotadas. Puedes inspeccionarlos, aplicarlos o descartarlos; la extensión ejecuta los controles disponibles después de aplicar.

Proveedores configurables

Conecta proveedores en la nube o modelos locales como Ollama y LM Studio. También incluye un motor local WebGPU/Wasm opcional. La privacidad depende del proveedor que elijas y de la configuración activa.

Flujo de ingeniería visible

Incluye controles del ciclo de vida, rutas a especialistas, señales derivadas del repositorio y gestión de deuda. Las métricas del historial Git son señales de actividad, no sustituyen datos de despliegue.

¿Para quién es Alpaquitay AI?

Para desarrolladores que usan asistentes de IA en VS Code y necesitan mantener requisitos, decisiones y revisión humana cerca del trabajo diario. Puede encajar en equipos que ya escriben criterios de aceptación o mantienen un archivo de especificación para cada iniciativa.

Cómo empezar

  1. Instala Alpaquitay AI desde Visual Studio Code Marketplace.
  2. Abre un proyecto y revisa el contexto que detectó la extensión.
  3. Configura un proveedor de IA; puedes empezar con Ollama o LM Studio local.
  4. Describe el cambio con criterios verificables y revisa el diff propuesto antes de aplicarlo.

Privacidad y código abierto

El proyecto tiene licencia MIT. Los proveedores locales procesan el trabajo en tu equipo; cuando configuras un proveedor en la nube, las solicitudes van a ese proveedor y se aplican los controles de privacidad descritos por el proyecto. La telemetría está desactivada por defecto. Consulta la política de privacidad y el código fuente antes de adoptarlo.
