SPEC-DRIVEN DEVELOPMENT · VS CODE

A VS Code AI extension that starts with the specification.

Alpaquitay AI helps turn requirements into reviewable changes. It organizes work around a specification, previews diffs before writing files, and records evidence from available checks.

Install from VS Code MarketplaceView source code

Specification before code

Alpaquitay uses `spec.md` and repository context to guide engineering tasks. Its workflow aims to make the goal, boundaries and verification clear before changes are accepted.

Review diffs before applying

Generated changes are presented as bounded proposals. Inspect, apply or discard them; the extension runs available checks after applying.

Configurable providers

Connect cloud providers or local models such as Ollama and LM Studio. An optional local WebGPU/Wasm engine is also available. Privacy depends on the provider and active settings you choose.

Visible engineering workflow

Includes lifecycle controls, specialist routing, repository-derived signals and debt tracking. Git-history metrics are activity signals; they do not replace deployment data.

Who is Alpaquitay AI for?

For developers using AI assistants in VS Code who want requirements, decisions and human review close to day-to-day work. It can fit teams that already write acceptance criteria or keep a specification file for each initiative.

Get started

  1. Install Alpaquitay AI from the Visual Studio Code Marketplace.
  2. Open a project and review the context detected by the extension.
  3. Configure an AI provider; Ollama or LM Studio are local options.
  4. Describe a change with verifiable criteria and inspect the proposed diff before applying it.

Privacy and open source

The project is licensed under MIT. Local providers process work on your machine; when you configure a cloud provider, requests go to that provider and follow the project's privacy controls. Telemetry is off by default. Review the privacy policy and source code before adoption.
