Inicio / Arquitectura SDD
Flujo de Trabajo de Ingeniería

Del problema al código. Sin improvisación.

Cada decisión arquitectónica queda registrada. Cada generación de IA tiene contexto cerrado y contratos estrictos.

01

SPEC antes de código

Define el problema de negocio, flujos de usuario, contratos de API estrictos y criterios de aceptación verificables. La IA recibe contexto completo sin suposiciones.

02

Validación multi-agente

Agentes especializados analizan la SPEC en paralelo: seguridad perimetral, lógica de dominio, UX y compliance. Cero bloqueantes antes de escribir código.

03

Generación limpia (1-Pass)

Una sola pasada de generación de código. Salida testeable, estructurada, documentada y estrictamente alineada con la arquitectura definida.

04

ADR + Review senior

El arquitecto de software valida el output, registra las decisiones técnicas en un ADR (Architecture Decision Record) y aprueba. La SPEC viaja con el Pull Request.

05

Deploy + observabilidad

Despliegue automatizado con feature flags, métricas de latencia p99, telemetría de tokens y logs de decisiones de IA trazables en producción.

## Contratos API
POST /auth/mfa/init
  body: { userId: string }
  resp: { challengeId: UUID, expiresAt: ISO8601 }

POST /auth/mfa/verify
  body: { challengeId: UUID, code: string }
  resp: { accessToken: JWT } | 401 Unauthorized

✅ Cobertura de tests ≥ 90%
