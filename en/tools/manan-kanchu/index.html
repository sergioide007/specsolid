CODE ANALYSIS · VS CODE

Review code risk signals from inside VS Code.

manan-kanchu combines heuristic rules, vulnerability patterns and optional AI analysis to help review code, policies and scripts before integrating them.

Install from VS Code MarketplaceView source code

Look for vulnerability patterns

The scanner includes CWE-referenced patterns for risks in application code, infrastructure as code and CI/CD pipelines. Findings point to areas for review; they do not replace a security audit.

Use authorship signals carefully

It blends heuristics with an optional semantic score. A score is a probabilistic signal: on its own, it cannot prove who wrote code or serve as conclusive evidence.

Evaluate policies

Includes security policy rules and lets you configure custom rules to fit a project's conventions.

Choose how to analyze

Heuristic analyzers can run without an AI provider. If you enable AI, you can configure local or cloud providers; code is sent to the provider you choose under its terms.

What does manan-kanchu mean?

The name comes from a Quechua expression the project translates as “there isn't.” The extension looks for things that should not be there: unsafe patterns, suspicious behavior or code whose origin deserves review.

What it includes

  • AI-generated code analysis using heuristics and an optional AI provider.
  • Vulnerability patterns for application languages, IaC and continuous integration.
  • Detection of malicious code categories such as keyloggers, exfiltration and miners.
  • Built-in policy rules and custom rules.
  • Dashboards and reports for reviewing findings.

Responsible use

AI and heuristic code-authorship analysis can produce false positives and false negatives. Do not use its output as the sole basis for disciplining someone, rejecting contributions or claiming where a code fragment came from. Validate every finding in context and with human review.

manan-kanchu is open source under the MIT license. Telemetry is off by default. Read the privacy policy and its limitations and responsible-use notes.
