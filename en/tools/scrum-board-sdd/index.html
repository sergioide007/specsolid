AGILE PLANNING · SPEC-DRIVEN DEVELOPMENT

A Scrum board that turns each sprint into a verifiable specification.

Organize backlog, capacity and sprint progress in a free, open board. Export the active sprint as SPEC.md to keep working criteria alongside your code.

Open Scrum Board SDDView source code

Plan with visible capacity

Organize stories and tasks in a backlog, then prepare a sprint around the team's available capacity.

Inspect progress

Review metrics such as burndown and historical velocity to discuss progress and adjust planning.

Connect a sprint to SPEC.md

Export the active sprint as a Markdown specification you can version with your code and use as reviewable engineering context.

Start without a cloud service

The board state is stored in your browser's local storage. Export a copy to preserve or version it; the board does not automatically sync between devices.

How it fits into Spec-Driven Development

  1. Prioritize the backlog and define the sprint goal.
  2. Select work that fits the team's capacity.
  3. Export scope and criteria as SPEC.md.
  4. Use that specification as reviewable input for implementation and verification.

Scrum Board SDD is an open tool for local planning. Its metrics support inspection; they do not replace team conversations or guarantee estimates.
