Manan kanchu AI

Extensión VS Code para detectar código generado por IA, vulnerabilidades de seguridad OWASP, malware y evaluar políticas de gobernanza. Del quechua: "lo que no existe" como trabajo humano auténtico.

VS Code Security OWASP AI Code Detector Licencia MIT

Malicious Code Scanner: keyloggers, exfiltración por DNS/HTTP, crypto miners
Policy Evaluator: 10 reglas de seguridad built-in + soporte de reglas personalizadas
Shell Analyzer: comandos destructivos (rm -rf, pipes remotos, escalada de privilegios)
