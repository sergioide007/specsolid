ANÁLISIS DE CÓDIGO · VS CODE

Revisa señales de riesgo en tu código desde VS Code.

manan-kanchu combina reglas heurísticas, patrones de vulnerabilidad y análisis opcional con IA para ayudar a revisar código, políticas y scripts antes de integrarlos.

Instalar desde VS Code MarketplaceVer código fuente

Busca patrones de vulnerabilidad

El escáner incluye patrones con referencias CWE para riesgos en código, infraestructura como código y pipelines CI/CD. Los hallazgos señalan lugares que requieren revisión; no sustituyen una auditoría de seguridad.

Examina señales de autoría con cuidado

Combina heurísticas con una puntuación semántica opcional. Una puntuación es una señal probabilística: por sí sola no demuestra quién escribió el código ni debe usarse como prueba concluyente.

Evalúa políticas

Incluye reglas de políticas de seguridad y permite configurar reglas propias para adaptar la revisión a las convenciones del proyecto.

Elige cómo analizar

Los analizadores heurísticos pueden ejecutarse sin proveedor de IA. Si habilitas IA, puedes configurar proveedores locales o en la nube; el código se envía al proveedor elegido según sus condiciones.

¿Qué significa manan-kanchu?

El nombre procede de una expresión quechua que el proyecto traduce como «no existe». La extensión busca aquello que no debería estar presente: patrones inseguros, comportamientos sospechosos o código cuyo origen conviene revisar.

Qué incluye

  • Análisis de código generado por IA con señales heurísticas y opción de proveedor de IA.
  • Patrones de vulnerabilidad para lenguajes de aplicación, IaC e integración continua.
  • Detección de categorías de código malicioso como keyloggers, exfiltración y mineros.
  • Reglas de política integradas y reglas personalizadas.
  • Paneles y reportes para revisar los hallazgos.

Uso responsable

El análisis de autoría de código mediante IA y heurísticas puede producir falsos positivos y falsos negativos. No uses sus resultados como única base para sancionar a una persona, rechazar contribuciones o afirmar la procedencia de un fragmento. Valida cada hallazgo con contexto y revisión humana.
